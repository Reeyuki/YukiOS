## Planned Features

- [ ] Desktop icon auto-sort rules (by name, type, recent use)

- [ ] Support for opening images in context menu with Paint
- [ ] Add vim/nano text editors

- [ ] From site to users computer file transfer support
- [ ] Add 3D os mode
- [ ] Add tiling wm mode
